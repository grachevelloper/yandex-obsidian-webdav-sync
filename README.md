# self-obsidian-yandex-sync

Personal-use Obsidian plugin by Nick Grachev for manual, two-way synchronization of notes and attachments with Yandex Disk over WebDAV.

The plugin runs inside Obsidian on desktop and mobile. It requires no backend, database server, or hosting. Files stay in the local vault and a dedicated Yandex Disk folder.

Implementation is developed in feature branches and reviewed through pull requests. Conflicting versions are preserved; deletions are not propagated.
